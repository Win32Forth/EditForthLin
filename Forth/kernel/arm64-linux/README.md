# linux-arm64 kernel (GNU as / AAPCS64)

ARM64 armasm under `../arm64` is the source of truth. The instructions stay
ARM64. `GrokTools/arm64_to_gas_linux.py` rewrites armasm directives, macros,
and the `adrp` / `add reg, reg, symbol` form (`:lo12:`) into ELF assembly.

| Path | Role |
| --- | --- |
| `asm/*.s` | Generated by `GrokTools/arm64_to_gas_linux.py` — do not edit |
| `asm/*.s.partN` | Continuation of a generated file that was split on a line boundary. `build-arm64.sh` concatenates the pieces before assembling |
| `identity.s` | Hand-written version / banner strings |

Regenerate:

```bash
python3 GrokTools/arm64_to_gas_linux.py
```

`bash build-arm64.sh` translates, assembles, and links
`Forth/build/arm64/fortharm64` on aarch64 Linux. The C host is
`Forth/host/linux/`. `_find_word` is a normal AAPCS64 function, so the
companion calls it directly.

Version strings live in `identity.s` (`2.5.6.1`, console `EditForthLin arm64`).
