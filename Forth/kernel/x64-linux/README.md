# linux-x64 kernel (NASM / System V)

ARM64 armasm under `../arm64` is the source of truth.

| Path | Role |
| --- | --- |
| `asm/*.asm` | Generated by `GrokTools/arm64_to_nasm_sysv.py` — do not edit |
| `asm/*.asm.partN` | Continuation of a generated file split on a line boundary. `build-x64.sh` concatenates the pieces before assembling |
| `vmregs.asm` | Hand-written virtual register file |
| `identity.asm` | Hand-written version / banner strings |
| `find_host.asm` | Hand-written System V wrapper for `_find_word` |

Regenerate:

```bash
python3 GrokTools/arm64_to_nasm_sysv.py
```

Assemble (ELF64):

```bash
mkdir -p Forth/build/x64-linux
nasm -f elf64 -o Forth/build/x64-linux/state.o Forth/kernel/x64-linux/asm/state.asm
# …same for each generated file, plus vmregs / identity / find_host
```

`./build-x64.sh` owns translate + assemble + host compile + ELF link of
`Forth/build/x64/forthx64` on Linux. On macOS it stops after assemble and
host compile-check.

Version strings live in `identity.asm` (`2.5.5.2`, console `EditForthLin x64`).
